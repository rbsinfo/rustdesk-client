rustdesk-client is a generator. It builds a branded, preconfigured remote-support client for Windows, macOS and Linux with GitHub Actions. Your name, your server and your key are compiled into the binary.

rustdesk-client est un générateur. Il compile avec GitHub Actions un client d'assistance à distance à votre nom et déjà configuré, pour Windows, macOS et Linux. Votre nom, votre serveur et votre clé sont compilés dans le binaire.

00 The modelLe modèle

Two repositories. No fork to keep in sync. Deux dépôts. Aucun fork à synchroniser.

The generator is generic. Everything that belongs to your organisation lives in a small repository you own, whose workflow calls the generator at a fixed ref.

Le générateur est générique. Tout ce qui relève de votre organisation vit dans un petit dépôt qui vous appartient, dont le workflow appelle le générateur à une référence fixe.

01 How it worksPrincipe

Three steps from nothing to a release. Trois étapes pour arriver à une release.

  1. 1

    Create your instanceCréez votre instance

    One script asks for the application name, company, bundle identifier, server host, server public key and an optional API URL. It creates your GitHub repository from the template.

    Un script demande le nom de l'application, la société, l'identifiant de bundle, l'hôte du serveur, sa clé publique et une URL d'API facultative. Il crée votre dépôt GitHub à partir du modèle.

    Needs git and gh. You can also copy template/ by hand.

    Nécessite git et gh. Vous pouvez aussi copier template/ à la main.

    shell
    git clone https://github.com/sadjo/rustdesk-client
cd rustdesk-client
scripts/new-instance.sh example-org/remote-support --private

  2. 2

    ConfigureConfigurez

    client.env holds the identity and the server. custom.json holds the RustDesk settings. Drop your icon in branding/. Nothing here is secret: all of it can be read from the client you distribute.

    client.env porte l'identité et le serveur. custom.json porte les réglages RustDesk. Déposez votre icône dans branding/. Rien ici n'est secret : tout se lit dans le client distribué.

    An invalid value stops the build with a message that names the key.

    Une valeur invalide arrête la compilation avec un message qui nomme la clé.

    client.env
    # Name shown to users, Windows executable, macOS bundle.
APP_NAME=Remote Support
COMPANY=Example Org
BUNDLE_ID=org.example.remotesupport

# Your server (hbbs) and the content of id_ed25519.pub.
SERVER_HOST=rustdesk.example.com
SERVER_KEY=AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA=

# Optional.
API_URL=
WEBSITE_URL=
SOURCE_URL=https://github.com/example-org/remote-support
ACCENT_COLOR=#1A2B3C
    custom.json
    {
  "conn-type": "incoming",
  "override-settings": {
    "hide-powered-by-me": "Y",
    "allow-auto-update": "N",
    "verification-method": "use-both-passwords"
  },
  "default-settings": {}
}

  3. 3

    BuildCompilez

    The workflow of your instance is a ten-line call to the generator. Run it by hand for test binaries. Push a tag to publish a release.

    Le workflow de votre instance tient en dix lignes : un appel au générateur. Lancez-le à la main pour des binaires de test. Poussez un tag pour publier une release.

    Builds run on GitHub-hosted runners and take about 30 to 60 minutes.

    Les compilations tournent sur les runners hébergés par GitHub et durent environ 30 à 60 minutes.

    .github/workflows/build.yml
    jobs:
  build:
    # Keep the ref after "@" and `generator-ref` identical.
    uses: sadjo/rustdesk-client/.github/workflows/build.yml@v1
    with:
      generator-ref: v1
      rustdesk-version: "1.5.3"
      targets: ${{ inputs.targets || 'windows,linux,macos' }}
      release-tag: ${{ startsWith(github.ref, 'refs/tags/') && github.ref_name || '' }}
    secrets: inherit
    shell
    git tag v1.0.0
git push origin v1.0.0

02 Platforms and outputsPlateformes et livrables

Six packages, one source archive, one checksum file. Six paquets, une archive de sources, un fichier de sommes de contrôle.

Built from the official RustDesk sources at a pinned tag, 1.5.3 by default. File names start with your application name.

Compilés à partir des sources officielles de RustDesk, à un tag fixé : 1.5.3 par défaut. Les noms de fichiers commencent par le nom de votre application.

Windows

x86_64

  • -windows-x86_64.exe
  • -windows-x86_64.msi

The executable runs without installation and can install the client. The MSI suits deployment tools.

L'exécutable se lance sans installation et peut installer le client. Le MSI convient aux outils de déploiement.

macOS

x86_64 · aarch64

  • -macos-x86_64.dmg
  • -macos-aarch64.dmg

One disk image for Intel, one for Apple Silicon. Ad hoc signed, or Developer ID signed and notarised with your secrets.

Une image disque pour Intel, une pour Apple Silicon. Signature ad hoc, ou Developer ID et notarisation avec vos secrets.

Linux

x86_64

  • -linux-x86_64.deb
  • -linux-x86_64.rpm

Debian and RPM packages. The package and the binary keep the upstream name rustdesk.

Paquets Debian et RPM. Le paquet et le binaire gardent le nom d'origine rustdesk.

SourceSources

AGPL-3.0

  • -source.tar.gz
  • SHA256SUMS

The RustDesk sources exactly as modified for your client, attached to every release.

Les sources de RustDesk exactement telles que modifiées pour votre client, jointes à chaque release.

03 FeaturesFonctions

Built for a support desk, not for a demo. Pensé pour un service d'assistance, pas pour une démo.

  • Incoming onlyRéception seule

    With "conn-type": "incoming" the client can be controlled but cannot connect to other devices. It is what the template builds.

    Avec "conn-type": "incoming", on peut prendre le contrôle du client, mais il ne peut pas se connecter à d'autres postes. C'est ce que produit le modèle.

  • Settings compiled inRéglages compilés

    Server, key and settings are part of the binary. No file next to the executable can change them. Preset passwords are refused: the binary is public.

    Le serveur, la clé et les réglages font partie du binaire. Aucun fichier posé à côté de l'exécutable ne peut les modifier. Les mots de passe prédéfinis sont refusés : le binaire est public.

  • No fork to maintainAucun fork à maintenir

    Your repository holds configuration, not RustDesk code. Moving to a newer generator means changing @v1 and generator-ref.

    Votre dépôt contient de la configuration, pas le code de RustDesk. Passer à un générateur plus récent revient à modifier @v1 et generator-ref.

  • Checked patchingModifications vérifiées

    Every edit of the RustDesk sources must match. If upstream changed, the build stops and names the pattern, instead of shipping a half-branded client.

    Chaque modification des sources de RustDesk doit correspondre. Si le code d'origine a changé, la compilation s'arrête et nomme le motif, au lieu de livrer un client à moitié personnalisé.

  • AGPL source attachedSources AGPL jointes

    Every release carries the complete corresponding source. The About page states that the client is a modified RustDesk and shows where its source lives.

    Chaque release embarque le code source correspondant complet. La page À propos indique que le client est un RustDesk modifié et où trouver ses sources.

  • Beyond name and iconAu-delà du nom et de l'icône

    Name, icons and accent colour come from configuration. Anything else in the interface is a .patch file in your patches/ directory.

    Le nom, les icônes et la couleur d'accent viennent de la configuration. Tout le reste de l'interface passe par un fichier .patch dans votre dossier patches/.

One-off or installed. The client runs without installation for a single session. Installed, it runs as a service for unattended access, including UAC prompts and the login screen.

Ponctuel ou installé. Le client se lance sans installation pour une session unique. Installé, il tourne en service pour l'accès sans surveillance, y compris sur les invites UAC et l'écran de connexion.

Console ready. With an API server (RustDesk Server Pro or a compatible console), each device appears with its ID, host name, user name, OS and version.

Prêt pour une console. Avec un serveur d'API (RustDesk Server Pro ou une console compatible), chaque poste apparaît avec son ID, son nom d'hôte, le nom d'utilisateur, le système et la version.

04 LimitationsLimites

What this first version does not do. Ce que cette première version ne fait pas.

Read this before you plan a rollout.

À lire avant de préparer un déploiement.

  • Desktop onlyPostes de travail uniquement

    Windows x86_64, macOS x86_64 and Apple Silicon, Linux x86_64. No Android, no iOS.

    Windows x86_64, macOS x86_64 et Apple Silicon, Linux x86_64. Ni Android, ni iOS.

  • Windows is not code-signed yetWindows n'est pas encore signé

    SmartScreen shows a warning on first launch. Signing integration is planned.

    SmartScreen affiche un avertissement au premier lancement. L'intégration de la signature est prévue.

  • macOS is ad hoc signed by defaultmacOS : signature ad hoc par défaut

    Without the four MACOS_* secrets, users must allow the application in System Settings > Privacy & Security, and grant Screen Recording and Accessibility again after each update.

    Sans les quatre secrets MACOS_*, l'utilisateur doit autoriser l'application dans Réglages Système > Confidentialité et sécurité, puis accorder de nouveau Enregistrement de l'écran et Accessibilité après chaque mise à jour.

  • Linux keeps the upstream nameLinux garde le nom d'origine

    The package and the binary are named rustdesk. The package cannot be installed next to the official one.

    Le paquet et le binaire s'appellent rustdesk. Le paquet ne peut pas cohabiter avec le paquet officiel.

  • Privacy screen imageImage de l'écran de confidentialité

    It cannot be customised yet.

    Elle n'est pas encore personnalisable.

  • One tested RustDesk versionUne seule version de RustDesk testée

    You can set rustdesk-version, but only the default is tested. If upstream changed, the build stops with the name of the pattern that no longer matches.

    Vous pouvez modifier rustdesk-version, mais seule la valeur par défaut est testée. Si le code d'origine a changé, la compilation s'arrête en nommant le motif qui ne correspond plus.

  • Private repositories use minutesLes dépôts privés consomment des minutes

    GitHub-hosted runners are free for public repositories. A private instance consumes Actions minutes, and macOS runners count ten times.

    Les runners hébergés par GitHub sont gratuits pour les dépôts publics. Une instance privée consomme des minutes Actions, et les runners macOS comptent dix fois.

  • You distribute, you publish the sourceVous distribuez, vous publiez les sources

    The AGPL-3.0 requires you to offer the complete corresponding source to everyone who receives the client. The archive is built for you. Making it reachable is your job.

    L'AGPL-3.0 vous impose de proposer le code source correspondant complet à toute personne qui reçoit le client. L'archive est produite pour vous. La rendre accessible reste à votre charge.
